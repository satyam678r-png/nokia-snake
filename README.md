# Nokia Snake

Classic Nokia-style Snake game.

## Features
- Nokia green screen look
- Arrow keys / WASD / on-screen D-pad / swipe
- Score + high score (saved in browser)
- Pause (Space / P / center button)
- Wall & self collision game over
- Mobile friendly

## Play
Open `index.html` or visit the Vercel deployment.

## Controls
| Input | Action |
|-------|--------|
| Arrow / WASD | Move |
| Space / Enter / Start | Start or Pause |
| P / Center button | Pause |
| Swipe on canvas | Move (mobile) |
